# 🚀 10 Minutes Survivor: Hero Arena

Проект игры для платформы **Яндекс Игры**.

## 📂 Структура проекта
* `GAME_DESIGN_DOCUMENT.md` — Полный геймдизайн-документ (оружие, синергии, герои, волны, баланс, монетизация).
* `src/` — Исходный код игры (будет создан при начале разработки).
* `assets/` — Спрайты, звуки, музыка и иконки.

## 🎯 Быстрый старт
1. Открой `GAME_DESIGN_DOCUMENT.md` для изучения игровой логики.
2. Выбери движок:
   - **Phaser 3** (рекомендуется для чистого HTML5/JS)
   - **Construct 3** (для быстрой визуальной сборки)
   - **Godot 4** (для удобного 2D-редактора)
3. Создай прототип передвижения и пула объектов.
