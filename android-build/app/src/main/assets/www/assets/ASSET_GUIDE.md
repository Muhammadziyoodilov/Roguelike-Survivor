# 🎨 РУКОВОДСТВО ПО ДОБАВЛЕНИЮ КАСТОМНОЙ ГРАФИКИ И АУДИО

Игра поддерживает **гибридную автозагрузку**:
* Если вы положите сюда свои PNG/MP3/OGG/WAV файлы — игра автоматически начнёт использовать их.
* Если какого-то файла нет — игра плавно использует процедурный генератор (ничего не сломается!).

---

## 🎵 1. ЗВУКИ И МУЗЫКА (`assets/audio/`)
Поддерживаемые форматы: `.mp3`, `.ogg`, `.wav`.

| Имя файла | Описание |
|---|---|
| `bgm_main.mp3` | Главный фоновый саундтрек игры (зациклен) |
| `sfx_slash.wav` | Взмах мечом / клинками |
| `sfx_shoot.wav` | Выстрел лука, сюрикена или фаербола |
| `sfx_hit.wav` | Удар по монстру / получение урона |
| `sfx_levelup.wav` | Повышение уровня / фанфара |
| `sfx_coin.wav` | Звон монет / покупка таланта |
| `sfx_gem.wav` | Сбор кристалла опыта |
| `sfx_chest.wav` | Открытие сундука сокровищ |
| `sfx_jackpot.wav` | Срыв джекпота x3 или x5 |
| `sfx_bomb.wav` | Взрыв Святой Бомбы |
| `sfx_freeze.wav` | Хрустальный звон Заморозки |
| `sfx_rage.wav` | Включение Режима Ярости |
| `sfx_boss.wav` | Предупреждающий рёв босса |
| `sfx_death.wav` | Звук гибели героя |
